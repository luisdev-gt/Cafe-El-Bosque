# Café El Bosque

A responsive promotional website developed for **Café El Bosque**, a fictional local coffee shop based in San Marcos, Guatemala.

This project was built as a portfolio piece based on a realistic client brief. The design, technical implementation, and user experience were developed independently from the client's functional requirements.

## Overview

Café El Bosque is a small coffee shop surrounded by nature, offering specialty coffee, cold beverages, pastries, and all-day breakfast.

The website is designed to provide visitors with a clear introduction to the business, showcase its menu and atmosphere, and make it easy for potential customers to get in touch.

The primary focus is a clean, modern, and responsive experience across mobile and desktop devices.

## Features

* Responsive layout optimized for mobile and desktop
* Hero section with primary calls to action
* About section introducing the business
* Categorized food and beverage menu
* Image gallery
* Contact information and location
* Business hours
* Direct WhatsApp contact button
* Smooth internal navigation between sections
* Accessible static frontend with no backend requirements

## Technologies

* **HTML5** — Semantic page structure and content
* **CSS3** — Custom styling, layout, and responsive design
* **JavaScript** — Client-side interactions and functionality
* **Bootstrap** — Responsive utilities and selected UI components
* **Git** — Version control
* **GitHub Pages** — Deployment and hosting

## Website Sections

### Home

Introduces the coffee shop through a prominent hero section featuring the business name, tagline, visual content, and primary calls to action.

### About

Provides a concise overview of the business, its atmosphere, and its offering.

### Menu

Presents the available products organized into three categories:

* Coffee
* Food
* Cold Beverages

### Gallery

A visual showcase featuring the coffee shop, beverages, food, and surrounding natural environment.

### Contact

Provides the information required for customers to reach the business, including:

* Phone number
* Location
* Opening hours
* WhatsApp contact

The website follows a responsive approach to ensure a consistent experience across different screen sizes.

Primary target devices include:

* Mobile phones
* Tablets
* Desktop computers

## Local Development

The project is entirely frontend-based and does not require a backend server or dependency installation.

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd cafe-el-bosque
```

The website can be opened directly through `index.html`.

For development, a local server such as **VS Code Live Server** can be used.
